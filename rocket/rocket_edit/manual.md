# ロケットゲーム操作マニュアル
## 入力デバイス対応状況
現在のバージョンでは、キーボード入力のみに対応しています。ゲームコントローラ（ゲームパッド）は現在サポートされていません。

## キーバインド一覧

### 基本操作
| キー | 機能 |
|------|------|
| スペースキー | ゲーム開始 / メインエンジン噴射 |
| R | ゲームリセット |
| エンターキー | ステージクリア後の次ステージへ進む / ゲームリセット |

### 飛行制御
| キー | 機能 |
|------|------|
| 上キー | スロットルを上げる（推力増加） |
| 下キー | スロットルを下げる（推力減少） |
| 左キー | 左に回転（反時計回り） |
| 右キー | 右に回転（時計回り） |

## ゲームの流れ

### ステージ1：打ち上げ
1. スペースキーでゲーム開始
2. スペースキーを押し続けてメインエンジンを噴射
3. 左右キーでロケットの姿勢を制御
4. 一定の高度に達するとステージクリア
5. エンターキーを押してステージ2へ進む

### ステージ2：着陸
1. 左右キーと推力を調整して発射台中央に着陸を試みる
2. または、チョップスティックにぶら下がる
   - ぶら下がり成功条件：衝突速度が0.5以下
   - 速度が速すぎるとぶら下がり機構が破壊される
   - ぶら下がり成功後は左右キーで揺れを制御可能

## ヒント
- スロットルを細かく調整することで、より精密な操作が可能
- 着陸時は低速で接地することが重要（速度0.5以下が安全）
- チョップスティックにぶら下がる際も低速接近が重要
- ぶら下がり成功後も左右キーで揺れを制御できる
